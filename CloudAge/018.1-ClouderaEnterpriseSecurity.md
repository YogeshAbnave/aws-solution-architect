## 🔧 Prerequisites & Environment Setup

### System Requirements

| Component | Minimum | Recommended | Notes |
|-----------|---------|-------------|-------|
| RAM | 32GB | 64GB+ | Per node |
| CPU | 8 cores | 16+ cores | Intel/AMD x64 |
| Storage | 500GB | 2TB+ | SSD preferred |
| Network | 1Gbps | 10Gbps | Low latency |
| OS | RHEL 7.9+ | RHEL 8.4+ | CentOS/Rocky supported |

### Operating System Configuration

```bash
# Set hostname (FQDN required for Kerberos)
sudo hostnamectl set-hostname master.hadoop.example.com

# Configure /etc/hosts with all cluster nodes
cat >> /etc/hosts << 'EOF'
10.0.1.10 master.hadoop.example.com master
10.0.1.11 worker1.hadoop.example.com worker1
10.0.1.12 worker2.hadoop.example.com worker2
10.0.1.13 edge.hadoop.example.com edge
EOF

# Disable SELinux (recommended for CDP)
sudo setenforce 0
sudo sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

# Configure firewall
sudo systemctl disable firewalld
sudo systemctl stop firewalld

# Set swappiness and transparent huge pages
echo 'vm.swappiness=1' >> /etc/sysctl.conf
echo never > /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/defrag
```

## 🔐 Kerberos Configuration

### Install MIT Kerberos KDC

```bash
# Install Kerberos packages
sudo yum install -y krb5-server krb5-libs krb5-workstation

# Configure /etc/krb5.conf
sudo cat > /etc/krb5.conf << 'EOF'
[logging]
 default = FILE:/var/log/krb5libs.log
 kdc = FILE:/var/log/krb5kdc.log
 admin_server = FILE:/var/log/kadmind.log

[libdefaults]
 dns_lookup_realm = false
 ticket_lifetime = 24h
 renew_lifetime = 7d
 forwardable = true
 rdns = false
 default_realm = HADOOP.EXAMPLE.COM
 default_ccache_name = KEYRING:persistent:%{uid}

[realms]
 HADOOP.EXAMPLE.COM = {
  kdc = master.hadoop.example.com
  admin_server = master.hadoop.example.com
 }

[domain_realm]
 .hadoop.example.com = HADOOP.EXAMPLE.COM
 hadoop.example.com = HADOOP.EXAMPLE.COM
EOF

# Configure KDC
sudo cat > /var/kerberos/krb5kdc/kdc.conf << 'EOF'
[kdcdefaults]
 kdc_ports = 88
 kdc_tcp_ports = 88

[realms]
 HADOOP.EXAMPLE.COM = {
  master_key_type = aes256-cts
  acl_file = /var/kerberos/krb5kdc/kadm5.acl
  dict_file = /usr/share/dict/words
  admin_keytab = /var/kerberos/krb5kdc/kadm5.keytab
  supported_enctypes = aes256-cts:normal aes128-cts:normal des3-hmac-sha1:normal arcfour-hmac:normal camellia256-cts:normal camellia128-cts:normal des-hmac-sha1:normal des-cbc-md5:normal des-cbc-crc:normal
 }
EOF

# Create KDC database
sudo kdb5_util create -s -P KDCMasterPassword123!

# Configure ACL
echo "*/admin@HADOOP.EXAMPLE.COM    *" > /var/kerberos/krb5kdc/kadm5.acl

# Start Kerberos services
sudo systemctl start krb5kdc
sudo systemctl start kadmin
sudo systemctl enable krb5kdc
sudo systemctl enable kadmin
```

### Create Service Principals

```bash
# Create admin principal
sudo kadmin.local -q "addprinc admin/admin@HADOOP.EXAMPLE.COM"

# Create Cloudera Manager principal
sudo kadmin.local -q "addprinc cloudera-scm/admin@HADOOP.EXAMPLE.COM"

# Create service principals for each host
for host in master worker1 worker2 edge; do
  sudo kadmin.local -q "addprinc -randkey hdfs/${host}.hadoop.example.com@HADOOP.EXAMPLE.COM"

  sudo kadmin.local -q "addprinc -randkey mapred/${host}.hadoop.example.com@HADOOP.EXAMPLE.COM"

  sudo kadmin.local -q "addprinc -randkey HTTP/${host}.hadoop.example.com@HADOOP.EXAMPLE.COM"

# Create user principals
```

## 🌐 TLS/SSL Configuration

### Generate SSL Certificates

```bash
# Create certificate directory
sudo mkdir -p /opt/cloudera/security/pki

# Generate private key
sudo openssl genrsa -out /opt/cloudera/security/pki/master.key 2048

# Generate certificate signing request
sudo openssl req -new -key /opt/cloudera/security/pki/master.key \
    -out /opt/cloudera/security/pki/master.csr \
    -subj "/C=US/ST=CA/L=SF/O=Example/OU=IT/CN=master.hadoop.example.com"

# Generate self-signed certificate (for testing)
sudo openssl x509 -req -days 365 \
    -in /opt/cloudera/security/pki/master.csr \
    -signkey /opt/cloudera/security/pki/master.key \
    -out /opt/cloudera/security/pki/master.crt

# Create Java keystore
sudo keytool -importcert -alias master -file /opt/cloudera/security/pki/master.crt \
    -keystore /opt/cloudera/security/pki/truststore.jks \
    -storepass changeit -noprompt

# Set proper permissions
sudo chown -R cloudera-scm:cloudera-scm /opt/cloudera/security/
sudo chmod 600 /opt/cloudera/security/pki/*.key
```

## 🗂️ HDFS Encryption Zones

### Setup Key Management Service (KMS)

```bash
# Create KMS keystore directory
sudo mkdir -p /var/lib/hadoop-kms/keystore
sudo chown kms:kms /var/lib/hadoop-kms/keystore
sudo chmod 700 /var/lib/hadoop-kms/keystore

# Generate encryption keys
sudo -u hdfs hadoop key create mykey1 -size 256
sudo -u hdfs hadoop key create mykey2 -size 256

# List available keys
sudo -u hdfs hadoop key list
```

### Create Encryption Zones

```bash
# Authenticate as hdfs user
kinit hdfs@HADOOP.EXAMPLE.COM

# Create directories for encryption zones
hdfs dfs -mkdir /zone1
hdfs dfs -mkdir /zone2

# Create encryption zones
hdfs crypto -createZone -keyName mykey1 -path /zone1
hdfs crypto -createZone -keyName mykey2 -path /zone2

# Verify encryption zones
hdfs crypto -listZones

# Test encryption
hdfs dfs -put /etc/passwd /zone1/
hdfs dfs -cat /zone1/passwd
```

### Backup and Recovery

#### Automated Backup Script
```bash
#!/bin/bash
# /opt/scripts/backup_cluster.sh

# Backup Hive Metastore
pg_dump -h localhost -U hive hive_metastore > /backup/hive_metastore_$(date +%Y%m%d).sql

# Backup Ranger policies
curl -u admin:admin "https://master.hadoop.example.com:6080/service/plugins/policies/exportJson" \
  > /backup/ranger_policies_$(date +%Y%m%d).json

# Backup HDFS metadata
sudo -u hdfs hdfs dfsadmin -saveNamespace
sudo -u hdfs hdfs dfsadmin -fetchImage /backup/fsimage_$(date +%Y%m%d)

# Backup Kerberos database
sudo kdb5_util dump /backup/kerberos_$(date +%Y%m%d).dump
```

## 🚨 Troubleshooting Guide

### Common Issues and Solutions

#### 1. Kerberos Authentication Failures
```bash
# Check KDC status
sudo systemctl status krb5kdc

# Verify principal exists
sudo kadmin.local -q "listprincs | grep hdfs"

# Check keytab file
sudo klist -kt /etc/hadoop/hdfs.keytab

# Synchronize time across all nodes
sudo ntpdate -s time.nist.gov
```

#### 2. HDFS SafeMode Issues
```bash
# Check HDFS status
hdfs dfsadmin -safemode get

# Force leave safemode (emergency only)
hdfs dfsadmin -safemode leave

# Check block reports
hdfs dfsadmin -report
```

#### 3. Service Start Failures
```bash
# Check Cloudera Manager logs
sudo tail -f /var/log/cloudera-scm-server/cloudera-scm-server.log

# Check service-specific logs
sudo tail -f /var/log/hadoop-hdfs/hadoop-hdfs-namenode-$(hostname).log

# Check process status
sudo systemctl status cloudera-scm-agent
```
