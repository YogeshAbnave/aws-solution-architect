## Hadoop Single Node Installation

### Step 1: Install Java
```bash
# Install OpenJDK 8
sudo apt-get install openjdk-8-jdk -y
```

### Step 2: Download and Install Hadoop
```bash
# Download Hadoop 1.2.1
wget https://archive.apache.org/dist/hadoop/common/hadoop-1.2.1/hadoop-1.2.1.tar.gz

# Extract and move to system directory
tar -xzvf hadoop-1.2.1.tar.gz
sudo mv hadoop-1.2.1 /usr/local/hadoop
```

### Step 3: Configure Environment Variables
```bash
# Edit bashrc file
nano ~/.bashrc

# Add these lines to bashrc:
export HADOOP_PREFIX=/usr/local/hadoop/
export PATH=$PATH:$HADOOP_PREFIX/bin
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export PATH=$PATH:$JAVA_HOME
```

### Step 4: Configure Hadoop Environment
```bash
# Edit hadoop-env.sh
nano /usr/local/hadoop/conf/hadoop-env.sh

# Add these lines:
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export HADOOP_OPTS=-Djava.net.preferIPV4Stack=true
```

### Step 5: Configure Core Hadoop Files

#### core-site.xml
```bash
nano /usr/local/hadoop/conf/core-site.xml
```
```xml
<property>
    <name>fs.default.name</name>
    <value>hdfs://localhost:9000</value>
</property>
<property>
    <name>hadoop.tmp.dir</name>
    <value>/usr/local/hadoop/HDFS</value>
</property>
```

#### hdfs-site.xml
```bash
nano /usr/local/hadoop/conf/hdfs-site.xml
```
```xml
<property>
    <name>dfs.replication</name>
    <value>1</value>
</property>
```

#### mapred-site.xml
```bash
nano /usr/local/hadoop/conf/mapred-site.xml
```
```xml
<property>
    <name>mapred.job.tracker</name>
    <value>hdfs://localhost:9001</value>
</property>
```

### Step 6: Initialize and Start Hadoop
```bash
# Create temporary directory
mkdir /usr/local/hadoop/tmp

# Apply environment changes
exec bash

# Format namenode
hadoop namenode -format

# Start Hadoop services
start-dfs.sh
start-mapred.sh

# Verify services are running
jps
```

## Java MapReduce Programming

### WordCount Example

#### Step 1: Create WordCount Java Program
```bash
cat > WordCount.java
```

#### Step 2: WordCount.java Code
```java
import java.io.IOException;
import java.util.*;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.conf.*;
import org.apache.hadoop.io.*;
import org.apache.hadoop.mapred.*;
import org.apache.hadoop.util.*;

public class WordCount {
    public static class Map extends MapReduceBase implements
    Mapper<LongWritable, Text, Text, IntWritable> {
        private final static IntWritable one = new IntWritable(1);
        private Text word = new Text();
        
        public void map(LongWritable key, Text value,
        OutputCollector<Text, IntWritable> output, Reporter reporter) throws IOException {
            String line = value.toString();
            StringTokenizer tokenizer = new StringTokenizer(line);
            while (tokenizer.hasMoreTokens()) {
                word.set(tokenizer.nextToken());
                output.collect(word, one);
            }
        }
    }
    
    public static class Reduce extends MapReduceBase implements
    Reducer<Text, IntWritable, Text, IntWritable> {
        public void reduce(Text key, Iterator<IntWritable> values,
        OutputCollector<Text, IntWritable> output, Reporter reporter) throws IOException {
            int sum = 0;
            while (values.hasNext()) {
                sum += values.next().get();
            }
            output.collect(key, new IntWritable(sum));
        }
    }
    
    public static void main(String[] args) throws Exception {
        JobConf conf = new JobConf(WordCount.class);
        conf.setJobName("wordcount");
        conf.setOutputKeyClass(Text.class);
        conf.setOutputValueClass(IntWritable.class);
        conf.setMapperClass(Map.class);
        conf.setReducerClass(Reduce.class);
        conf.setInputFormat(TextInputFormat.class);
        conf.setOutputFormat(TextOutputFormat.class);
        FileInputFormat.setInputPaths(conf, new Path(args[0]));
        FileOutputFormat.setOutputPath(conf, new Path(args[1]));
        JobClient.runJob(conf);
    }
}
```

#### Step 3: Compile and Package
```bash
# Set classpath
export CLASSPATH=/usr/local/hadoop/hadoop-core-1.2.1.jar

# Create directory for compiled classes
mkdir wordcount_classes

# Compile Java code
javac -d wordcount_classes/ WordCount.java

# Create JAR file
jar -cvf wordcount.jar -C wordcount_classes/ .
```

#### Step 4: Run WordCount Job
```bash
# Create input file
nano input.txt

# Upload to HDFS
hadoop fs -put input.txt .

# Run MapReduce job
hadoop jar wordcount.jar WordCount input.txt result

# View results
hadoop fs -lsr /user/ubuntu/result
hadoop fs -get /user/ubuntu/result/part-00000 results
sort -n -k2 results > sorted_result
cat sorted_result
```

## Apache Flume (Data Ingestion)

### Purpose
Apache Flume is used for efficiently collecting, aggregating, and moving large amounts of log data from various sources to HDFS.

### Step 1: Install Flume
```bash
# Update system
sudo apt-get update && sudo apt-get upgrade -y

# Download Flume
wget http://archive.apache.org/dist/flume/1.4.0/apache-flume-1.4.0-bin.tar.gz

# Extract
tar -zxvf apache-flume-1.4.0-bin.tar.gz
```

### Step 2: Configure Flume Environment
```bash
# Navigate to conf directory
cd apache-flume-1.4.0-bin/conf/

# Create flume-env.sh from template
mv flume-env.sh.template flume-env.sh

# Edit environment file
nano /home/ubuntu/apache-flume-1.4.0-bin/conf/flume-env.sh
```

Add these lines:
```bash
JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
FLUME_CLASSPATH="/home/ubuntu/apache-flume-1.4.0-bin/lib/*.jar"
```

### Step 3: Create Flume Configuration
```bash
nano flume.conf
```

```properties
# Flume agent config
cloudage.sources = eventlog
cloudage.channels = file_channel
cloudage.sinks = sink_to_hdfs

# Define / Configure source
cloudage.sources.eventlog.type = exec
cloudage.sources.eventlog.command = tail -F /var/log/flume/event.log
cloudage.sources.eventlog.restart = true
cloudage.sources.eventlog.batchSize = 1000

# HDFS sinks
cloudage.sinks.sink_to_hdfs.type = hdfs
cloudage.sinks.sink_to_hdfs.hdfs.fileType = DataStream
cloudage.sinks.sink_to_hdfs.hdfs.path = hdfs://localhost:9000/user/ubuntu/flume/events
cloudage.sinks.sink_to_hdfs.hdfs.filePrefix = event
cloudage.sinks.sink_to_hdfs.hdfs.fileSuffix = .log
cloudage.sinks.sink_to_hdfs.hdfs.batchSize = 1000

# Use a channel which buffers events in memory
cloudage.channels.file_channel.type = file
cloudage.channels.file_channel.checkpointDir = /var/log/flume/checkpoint
cloudage.channels.file_channel.dataDirs = /var/log/flume/data

# Bind the source and sink to the channel
cloudage.sources.eventlog.channels = file_channel
cloudage.sinks.sink_to_hdfs.channel = file_channel
```

### Step 4: Setup Log Directories
```bash
# Create required directories
sudo mkdir /var/log/flume/
sudo mkdir /var/log/flume/checkpoint/
sudo mkdir /var/log/flume/data/
sudo chmod 777 -R /var/log/flume

# Create HDFS directory
hadoop fs -mkdir hdfs://localhost:9000/user/ubuntu/flume/events
```

### Step 5: Setup Log Generator
```bash
# Download log generator
wget https://s3.amazonaws.com/cloud-age/generate_logs.py

# Move configuration file
mv flume.conf apache-flume-1.4.0-bin/conf/
```

### Step 6: Run Flume Agent
```bash
# Start Flume agent
cd apache-flume-1.4.0-bin/bin
./flume-ng agent --conf /home/ubuntu/apache-flume-1.4.0-bin/conf/ --conf-file /home/ubuntu/apache-flume-1.4.0-bin/conf/flume.conf --name cloudage
```

### Step 7: Generate Log Data (in separate terminal)
```bash
# Monitor logs (Terminal 2)
tail -F /var/log/flume/event.log

# Generate logs (Terminal 1)
sudo python generate_logs.py
```

Apache Sqoop is used for efficiently transferring bulk data between Apache Hadoop and structured datastores such as relational databases.

### Step 1: Install Sqoop

```bash
wget http://archive.apache.org/dist/sqoop/1.4.4/sqoop-1.4.4.bin__hadoop-1.0.0.tar.gz

sudo mv sqoop-1.4.4.bin__hadoop-1.0.0 /usr/local/sqoop/
```

### Step 2: Configure Environment
```bash
# Edit bashrc
nano ~/.bashrc

# Add Sqoop environment variables:
export SQOOP_PREFIX="/usr/local/sqoop/"
export SQOOP_CONF_DIR="$SQOOP_PREFIX/conf"
export SQOOP_CLASSPATH="$SQOOP_CONF_DIR"
export PATH="$SQOOP_PREFIX/bin:$PATH"
```

Add these lines:
```bash

export HADOOP_MAPRED_HOME=/usr/local/hadoop/
export ZOOKEPER_HOME=$ZOOKEEPER_HOME
```

## Troubleshooting Tips

### Common Issues and Solutions

1. **Java Path Issues**
   - Verify JAVA_HOME: `echo $JAVA_HOME`
   - Find Java installation: `which java`

2. **Hadoop Services Not Starting**
   - Check if SSH is working: `ssh localhost`
   - Verify Hadoop configuration files
   - Check logs in: `/usr/local/hadoop/logs/`

3. **Permission Denied Errors**
   - Set proper permissions: `chmod 755 /usr/local/hadoop/bin/*`
   - Check HDFS permissions: `hadoop fs -chmod -R 777 /tmp`

4. **Port Conflicts**
   - Check if ports 9000, 9001 are free: `netstat -tulpn | grep 900`
   - Kill conflicting processes if needed

5. **MySQL Connection Issues**
   - Verify MySQL is running: `service mysql status`
   - Check MySQL logs: `sudo tail -f /var/log/mysql/error.log`
